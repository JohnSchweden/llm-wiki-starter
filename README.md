# llm-wiki-starter

An empty LLM wiki with three sample sources, two articles and four skills. Open the folder in Obsidian, let an AI agent (Claude Code, Codex or the Copilot plugin) read `AGENTS.md`, and start adding sources.

Built for the workshop "LLM Wiki From First Principles" (Agentic Economy Forum, Build Arena, Berlin, 14 October 2026). Pattern by Andrej Karpathy; wiki skill by Yuhan Lei (MIT, see `.agents/skills/karpathy-llm-wiki/LICENSE`).
